# دارایی‌های ساخت

این‌ها منبعِ ساختِ دارایی‌های `public/` هستند و از پوشه‌ی موقتِ سشن
این‌جا منتقل شده‌اند تا با بسته‌شدن سشن از دست نروند.

| فایل | نقش |
|---|---|
| `aligned-lit.jpg` | منبعِ هم‌ترازشده‌ی نسخه‌ی روشنِ هیروی ۱ |
| `aligned-dark.jpg` | منبعِ هم‌ترازشده‌ی نسخه‌ی تاریکِ هیروی ۱ |
| `edit2.py` | خط لوله‌ی تدوین ویدیوی هیروی ۳ (برش، تاری، اسلوموشن) |
| `align2.py` | هم‌ترازی جفت روشن/تاریک با جست‌وجوی مقیاس و انتقال |
| `verify.py` | اعمال تبدیل هم‌ترازی و ذخیره‌ی جفت |
| `grade2.py` | خط لوله‌ی نورپردازی از عکس واقعی (بازنشسته) |
| `rebuild2.py` | ماسک‌زنی و پایدارسازی لوپ (بازنشسته) |
| `sara-cut.png` | سارا، بریده از عکس خامِ `ax sara/2322.jpg` — منبعِ هیروی ۲ |
| `cut-sara.py` | ساختِ همان برش (rembg + آستانه + بزرگ‌ترین ناحیه‌ی پیوسته) |
| `swap.py` | هم‌ترازیِ برش با ساراىِ گرافیکِ فعلی، با IoU سیلوئتِ سر و بالاتنه |
| `swapfit.npy` | نتیجه‌ی همان هم‌ترازی: `[IoU, scale, tx, ty]` در مختصات پروکسی ۱۳۷۶×۷۶۸ |
| `finalize.py` | ترکیب، تطبیق تُن، پرکردنِ حفره‌ها و خروجی‌های هیروی ۲ |
| `retype.py` | بازگرداندنِ امضا و پاراگراف *روی* سارا + خروجی نهایی |

| `hero4-layers.py` | استخراج لایه‌های تایپِ هیروی ۴ از گرافیکِ مرجع |
| `hero4-bg.py` | زمینه‌ی هیروی ۴ با پرکردنِ انتشاری جای حروف و سارا |
| `hero4-sara.py` | لایه‌ی سارا برای هیروی ۴ (سیلوئتِ خودِ گرافیک) |
| `mcur.npy` | سیلوئتِ ساراىِ گرافیکِ مرجع در ۲۷۵۲×۱۵۳۶ — کشِ rembg |

ترتیب اجرای هیروی ۲: `cut-sara.py` → `swap.py` → `finalize.py` → `retype.py`.
ترتیب اجرای هیروی ۴: `hero4-layers.py` → `hero4-bg.py` → `hero4-sara.py`.
(`finalize.py` ماتِ ساراىِ گرافیکِ فعلی را در `mcur.npy` کش می‌کند تا اجرای
دوباره‌اش rembg نخواهد.)

اسکریپت‌های پایتون به `imageio-ffmpeg`, `Pillow`, `numpy`, `rembg`,
`arabic-reshaper` و `python-bidi` نیاز دارند.
